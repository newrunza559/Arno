ใน Project ที่กลุ่มผมทำ คือการทำระบบจองคิวห้องพักในโรงแรมที่ชื่อว่า Hotel Luna และยังสามารถกดสั่งอาหารในเว็บได้เลย ซึ่งเมื่อเข้ามาในหน้าแรก จะเป็นหน้าที่ยังไม่ login ซึ่งจะไม่สามารถกดปุ่มหรือทำอะไรได้เลย เพื่อเป็นการบังคับให้ผู้ใช้งานทุกคนล็อคอิน ปุ่มล็อคอินจะอยู่มุมบนขวามือ ในการล็อคอิน จะแบ่งเป็น 2 แบบคือ User : admin ใน user นี้
จะมีปุ่มเพิ่มขึ้นมา 2 ปุ่ม คือ room_list คือ หน้าที่เอาไว้สำหรับให้ admin เข้าไปกดให้ห้องว่างหรือไม่ว่างได้ และ dashboard คือหน้าที่เอาไว้ให้ admin ยกเลิกการจองของลูกค้า เมื่อกดยกเลิกการจอง ปุ่ม ไม่ว่างในหน้าหลักก็จะกลับมาว่างเป็นอัตโนมัติ ส่วน User อีกแบบจะเป็น User ธรรมดา ซึ่งสามารถใช้งานได้แค่จองคิวห้องพักและกดสั่งอาหารได้แค่นั้น 
และในหน้ากดจองห้องพักเมื่อกดปุ่ม Book Now เว็บจะพาไปหน้า เลือกวัน Check In และ Check Out สามารถเลือกวันที่ได้เลย เมื่อกดจอง ตัวเว็บจะเด้งกลับมาที่หน้าหลักและจากปุ่ม Book Now จะกลายเป็นปุ่มสีเทา Not Available นั้นคือห้องนั้นถูกจองไปแล้ว ซึ่งการจะยกเลิกการจองได้จะต้องทำการติดต่อกับพนักงานเท่านั้น 
ต่อไปเมื่อต้องการสั่งอาหาร สามารถเลือกรายการอาหารและกดใส่ตะกร้าสินค้าได้ เมื่อใส่ตะกร้า เว็บจะพามาหน้า Cart ของคุณ เพิ่อเป็นการสรุปยอดและยังสามารถกดลบรายการอาหารได้ ก่อนสั่ง และเมื่อกด Proceed to order เว็บจะพาไปหน้า confirm เพิ่อเป็นการยืนยันในการสั่งอาหาร ตัวเว็บของเรามีเนื้อหาประมาณนี้ขอบพระคุณครับ
